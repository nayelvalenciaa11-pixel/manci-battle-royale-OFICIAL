Mover: W A S D. Apuntar: mouse. Disparar: clic. Apuntar: clic derecho (mantener). Francotirador: rueda del mouse o Z cambia el zoom. Correr: Shift. Saltar: Espacio. Arrodillarse: Ctrl izquierdo o C (alternar). Cuerpo a tierra: X (alternar; Saltar o Correr te levantan). Granada: G (mantener para ver la trayectoria, soltar para lanzar). Recargar: R. Armas: teclas 1 a 9, rueda del mouse, o Q para el menú. Humo morado: H (mantener para ver la trayectoria, soltar para lanzar). Soltar el mouse: Esc. Personalizar botones y HUD: tecla O.
Mover: arrastra con el pulgar izquierdo. Apuntar: arrastra con el derecho. Disparar: botón amarillo (si lo mantienes y arrastras, también apuntas). Recargar: botón Recargar. Apuntar: botón Apuntar (con el francotirador, tócalo otra vez para más zoom). Correr (a la izquierda), Agachar y Tumbarse (cuerpo a tierra) se encienden y apagan al tocarlos; Saltar es un toque. Granada: mantén el botón Granada para ver la trayectoria y suéltalo para lanzar. Humo morado: igual con el botón Humo. Cambiar arma: toca la barra de armas de abajo (toca otra vez el arma elegida para abrir el menú).
